# Code of Conduct

## Our Standard

Sticker Studio is a collaborative project created by Mila Le and Cruz Le.

We expect everyone participating in the project to:

- Be respectful and considerate.
- Communicate constructively.
- Welcome questions, suggestions, and different perspectives.
- Give appropriate credit for others' work.
- Respect intellectual property and licensing.
- Keep discussions focused on improving the project.
- Avoid harassment, discrimination, personal attacks, or intentionally disruptive behavior.

## Contributions

Contributors should make a good-faith effort to communicate clearly and work cooperatively with the Sticker Studio team.

Criticism of code, designs, ideas, or implementation decisions is welcome when it is constructive and respectful.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks or threats.
- Deliberate disruption of the project or its community.
- Sharing private or sensitive information without permission.
- Misrepresenting someone else's work as your own.
- Deliberately violating licenses or intellectual property rights.
- Any other conduct that would make the project an unsafe or hostile environment.

## Reporting

If you experience or observe behavior that violates this Code of Conduct, please contact the Sticker Studio project owners privately.

For security vulnerabilities, please follow the instructions in `SECURITY.md` instead of publicly reporting the vulnerability.

## Enforcement

The Sticker Studio project owners may take appropriate action in response to violations of this Code of Conduct, including removing inappropriate content, restricting participation, or taking other reasonable steps to protect the project and its community.

## Attribution

This Code of Conduct was written for Sticker Studio and may be updated as the project and community develop.
