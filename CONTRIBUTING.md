# Contributing to Sticker Studio

Thank you for contributing to Sticker Studio!

Sticker Studio is a collaborative project created by Mila Le and Cruz Le.

## Development Workflow

1. Create a branch for your change.
2. Make and test your changes locally.
3. Commit your changes with a clear commit message.
4. Open a Pull Request.
5. Review the changes.
6. Merge the Pull Request into `main` when it is ready.

## Branch Naming

Use descriptive branch names:

- `feature/feature-name`
- `fix/bug-name`
- `docs/documentation-name`
- `refactor/change-name`

## Pull Requests

Pull Requests should:

- Clearly explain what was changed.
- Explain why the change was made when necessary.
- Be tested before submission.
- Avoid unrelated changes.
- Keep sensitive information such as API keys and passwords out of the repository.

## Code Quality

Before submitting a Pull Request:

- Make sure the project builds successfully.
- Check for TypeScript errors.
- Run the project's linting tools.
- Test the affected functionality.

## Questions

For questions about development, discuss them with the Sticker Studio team before making major architectural changes.
